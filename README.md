# Gilles Momeni — Portfolio & 3D Web Experience

Creative Software Engineer, Fullstack & Mobile App Developer portfolio built with Three.js, WebGL, GSAP, Vite, and TypeScript.

## 🚀 Features & Modernizations

- **TypeScript Migration**: Entire codebase converted from JavaScript to strict TypeScript.
- **Three.js & GSAP Animations**: Interactive 3D room model with custom scroll-driven GSAP camera and model animations.
- **Modern Content & Portfolio Update**: Updated project showcase with Zepythagore, FarmAssist, Autospace, Parking Management with ALPR Simulator, Xmoni, and x-anatomy.
- **Accessibility & UX Improvements (Palette UX)**:
  - Skip-to-content keyboard link for screen readers.
  - Visible focus indicators (`:focus-visible`) across all interactive elements.
  - Accessible dark/light mode toggle button with dynamic ARIA attributes (`aria-pressed`, `aria-label`).
  - High contrast ratio colors meeting WCAG guidelines.
  - Mobile responsive layouts and smooth scrolling with ASScroll.
- **SEO Optimized**: Complete Open Graph, Twitter Cards, meta tags, and structured JSON-LD data for search engine visibility.
